1. 应该被隐藏的广告位

这些选择器是 EasyList 通用 cosmetic 规则里真实存在的（## 后面那部分）， 不是随便起的 class 名 —— 随便起的名字 EasyList 不会覆盖，测了也是白测。

广告位：ins.adsbygoogle[data-ad-client]
广告位：#Ad-Container
广告位：#ad-banner-top
广告位：.ad-unit
广告位：.sponsored-post

2. 必须保留的正文

这一段必须一直可见。如果它消失了，说明某条 cosmetic 规则太宽。

3. 应该被拦截的请求

这些指向内置 starter list 里的广告域名，所以即使 EasyList 还没下载完也应该被拦掉。

4. 本站请求，不应被拦截

由 JavaScript 在两秒后注入。stylesheet 对后续新增的节点依然生效，所以它应该照样被隐藏， 不需要 MutationObserver。
